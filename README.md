# 추리 퍼즐 — 탐정의 해답
행과 열, 색깔 구역의 단서를 조합해 보드에 탐정을 배치하는 연역 추리 퍼즐입니다. 한국어와 영어를 지원하며, 모바일과 데스크톱에서 플레이할 수 있습니다.

#### 게임 규칙
- 각 가로줄과 세로줄에 탐정을 한 명씩 배치합니다.
- 각 색깔 구역에도 탐정을 한 명씩 배치합니다.
- 탐정끼리 대각선을 포함한 8방향으로 맞닿을 수 없습니다.
- 틀린 배치를 세 번 하면 수사가 종료됩니다.

#### 조작
- 짧게 클릭하거나 터치해 칸에 ✕ 표시를 합니다. 다시 누르면 표시를 지울 수 있습니다.
- 길게 누르거나 같은 칸을 빠르게 두 번 눌러 탐정을 배치합니다. 마우스 오른쪽 클릭으로도 배치할 수 있습니다.
- 드래그해 여러 칸을 연속으로 표시할 수 있습니다.
- 힌트는 탐정 한 명을 배치합니다. 사건마다 최대 3회 사용할 수 있습니다.
- 자동소거는 현재 단서상 불가능한 칸을 표시합니다. 스테이지당 한 번 사용할 수 있습니다.
- 되돌리기와 힌트는 키보드 Z 또는 Ctrl+Z, H로도 사용할 수 있습니다.

#### 설정과 진행 저장
설정에서 한국어·영어, 5×5부터 8×8까지의 보드 크기, 사운드를 선택할 수 있습니다. 진행 중인 보드, 해금한 사건, 점수 기록과 설정은 브라우저의 localStorage에 저장됩니다. 설정에서 전체 저장 데이터를 초기화할 수 있습니다.

#### 기술 구성
- React 19, TypeScript, Vite 8
- Tailwind CSS 4
- Motion, Lucide React
- 퍼즐 생성과 저장 로직: src/utils/puzzle.ts, src/utils/storage.ts
- 화면과 게임 흐름: src/App.tsx, src/components/
